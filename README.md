# Openfield

> Room to think.

A mental-health consultancy site: licensed practitioners, live availability, and
booking that does not require an account.

Built with Next.js 16 (App Router), React 19, Tailwind CSS v4 and Supabase.

---

## Getting started

```bash
npm install
cp .env.example .env.local   # fill in your Supabase values
npm run dev
```

Open <http://localhost:3000>.

### Environment

| Variable | Required | Notes |
| --- | --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | yes | Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | yes | Publishable key. Safe in the browser. |
| `SUPABASE_SERVICE_ROLE_KEY` | no | Server only. Bypasses RLS — never expose it. |
| `NEXT_PUBLIC_SITE_URL` | yes | Used for canonical URLs and auth redirects. |
| `RESEND_API_KEY` | no | Transactional email (not yet wired). |
| `CRON_SECRET` | no | Guards the reminder route. |

`src/lib/env.ts` validates these at boot, so a missing value fails the build
rather than a user request.

## Architecture

```
src/
├─ app/
│  ├─ (marketing)/     home, about, services, therapists, journal, crisis support
│  ├─ (auth)/          login, signup
│  ├─ book/            5-step booking flow
│  ├─ account/         client's own sessions
│  └─ auth/callback/   email confirmation exchange
├─ components/
│  ├─ layout/          header, footer, containers, torn edge
│  ├─ marketing/       page sections
│  ├─ booking/         flow + month calendar
│  ├─ ui/              button, price tag
│  └─ icons/           24 generated monoline icons (see below)
├─ content/            copy, site config, asset registry, partners
├─ lib/                supabase clients, queries, server actions, booking maths
└─ types/              generated database types
```

### Data

Supabase Postgres. The important pieces:

- **`get_available_slots(therapist, service, from, to)`** derives open times from
  `availability_rules`, subtracting existing appointments and `time_off`.
- **`book_appointment(...)`** is the only write path. It is `SECURITY DEFINER`,
  reads price and duration from the catalogue rather than trusting the client,
  re-validates the slot, and works with or without a signed-in user.
- **`appointments_no_overlap`** is a GiST exclusion constraint on
  `(therapist_id, tstzrange(starts_at, ends_at))`. Double-booking is impossible
  at the database level, not merely discouraged in the UI.
- **RLS is on for every table.** Policy helpers live in a `private` schema so
  PostgREST does not expose them while policies can still call them.

Migrations are in `supabase/migrations/`.

### Booking without an account

Appointments carry either a `client_id` or guest contact details, enforced by a
check constraint. Guests get a booking reference; signing in is optional and
only exists so returning clients can see their sessions together.

## Design system

Tokens live in `src/app/globals.css` under `@theme`. No raw hex outside that
file.

| Token | Value | Use |
| --- | --- | --- |
| `--color-ink` | `#131316` | Text, dark surfaces |
| `--color-page` | `#f1f1f1` | Page background |
| `--color-paper` | `#ffffff` | Cards, inputs |
| `--color-signal` | `#00d54b` | Primary action **fill only** |

**Green is a fill, never a text colour.** `#00d54b` on `#f1f1f1` is about
1.7:1 and unreadable; ink on green is 9.39:1. Prices render as green tags for
that reason.

Type: DM Sans (display), Open Sans (body), Montserrat Alternates (micro-caps and
the wordmark).

House rules, enforced in review: no gradients, no shadows beyond one elevation
token, no sparkle/zap/bot iconography, no emoji.

### Motion

- `SmoothScroll` — Lenis. It interpolates the **real** document scroll, so
  `window.scrollY`, IntersectionObserver and `useScroll` all keep working.
- `BlurText` / `BlurIn` — word-by-word blur reveal on scroll-in, fires once.
- `ScrollMedia` — scroll-linked parallax on full-bleed photography.
- `Reveal` — plain fade/rise for blocks that are not text.

Lenis notes, because smooth scroll is easy to break things with:

- Touch devices keep **native** scrolling. Momentum on momentum feels wrong on
  a phone and costs battery for nothing.
- `scroll-behavior` must stay unset in CSS — it fights Lenis.
- In-page anchors are routed through `lenis.scrollTo`, otherwise the browser
  jumps and Lenis drags it back.
- Full-screen overlays must call `stopSmoothScroll()`; `overflow: hidden`
  alone does not stop it.

All three collapse to a static end state under `prefers-reduced-motion`, and
the text is real DOM content so it reads correctly if the animation never
runs.

## Assets

Every image is local — `next.config.ts` declares no `remotePatterns`, so an
external URL fails to load rather than slipping in.

- `content/image-metadata.ts` is generated by the pipeline in `output/imagegen`
  and carries dimensions, alt text and blur placeholders.
- `src/content/assets.ts` resolves paths through it and **throws at build time**
  for an unknown path.
- Icons: edit `public/icons/*.svg`, then `node scripts/build-icons.mjs`.

### Image quality

`next/image` **always re-encodes**. A pristine source JPEG is still put through
the optimiser, so an `<Image>` with no `quality` prop is served at Next's
default of **75** no matter how good the file on disk is.

Every `<Image>` therefore passes an explicit tier from `IMAGE_QUALITY` in
`src/content/assets.ts`:

| Tier | Value | Used for |
| --- | --- | --- |
| `hero` | 92 | Full-bleed heroes, big-type band |
| `feature` | 90 | Editorial bands, portraits, journal covers, card art |
| `thumb` | 86 | Small cards, avatars, marquee marks |

Any value used there **must** also appear in `images.qualities` in
`next.config.ts` — Next 16 silently coerces anything else to the nearest
allowed value. Keep the two lists in step.

Source files are exported large (heroes at 2880w, JPEG q92 / WebP q92 /
AVIF q70) so the optimiser always has more detail than it needs. Next serves
the right size per breakpoint from `deviceSizes`, up to 3840.

### Before launch

Some content is deliberately marked as placeholder and should be replaced:

- Practitioner portraits and biographies (`therapists.is_placeholder = true`)
- Partner logos in `src/content/partners.tsx` — all invented; do not substitute
  a real company's mark without written agreement
- Crisis-line numbers on `/crisis-support` (`TODO(region)`)
- The `12,400+ sessions` figure in `src/content/copy.ts`
